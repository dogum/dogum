### ⚙️ Featured: [ML Ratchet](https://github.com/dogum/ML-Ratchet)

**Trained on physics. Graded on reality.**

Nine numpy-only neural networks that learned purely from physics simulations laid into real instrument noise. A new version is kept only if it beats the last one, and each model sits one final exam on real data it never saw. Wins *and* losses are published.

| Model | Reads | Model | Reads |
|---|---|---|---|
| ChirpNet | LIGO black-hole and neutron-star mergers | QuakeNet | Earthquake size, distance and depth from one seismometer |
| TransitNet | Exoplanet transits in TESS light curves | StarQuake | Red-giant mass and radius from how the star rings |
| SunDoctor | Why a solar farm underperformed | CellSense | Battery wear and remaining cycles |
| BearingNet | Machine bearing defects | SwellCast | Distance to the storm behind incoming swell |
| BeatNet | Heartbeat classes on ECG *(research only)* | | |

**0** real labelled training examples · **61** ratchet decisions logged, **24** rejected · every model [runs live in your browser](https://dogum.github.io/ML-Ratchet/#live)
